PureFunction Backup

PureFunction Backup is a private, automated disaster-recovery utility operated solely by the Pure Function project owner. It creates encrypted backups of the project's Supabase backend and stores them in a dedicated folder in the project owner's Google Drive.

Read Privacy Policy
Separate from the Pure Function coaching app: PureFunction Backup is an internal infrastructure backup tool, not a public consumer application. Coaching clients and coaches do not sign in with Google or interact with this tool.

What PureFunction Backup Does

  • Reads a point-in-time snapshot of the Pure Function Supabase project (PostgreSQL schemas, authentication metadata, and private storage objects) in read-only mode.
  • Compresses and encrypts every archive locally with AES-256-GCM (PFBK1 format with scrypt key derivation) and verifies the decryption checksum before any file is uploaded.
  • Uploads only the encrypted archive (.tar.gz.enc) and a non-PII verification manifest (.manifest.json) into a dedicated backup folder (default: PureFunction-Encrypted-Backups) in the project owner's Google Drive.
  • Manages retention inside that folder by deleting expired backup archives and matching manifests past the configured retention window (default: 30 days) while always preserving at least the newest configured minimum backups (default: 7).

Google Drive Permission Scope

PureFunction Backup requests only the single, least-privilege OAuth 2.0 scope https://www.googleapis.com/auth/drive.file.

This restricts access strictly to the backup folder and backup files created by PureFunction Backup itself. The utility cannot view, list, read, modify, or delete any other files or folders in the owner's Google Drive, and it does not request access to any other Google service.

Privacy & Data Handling

Full details on Google Drive API usage, encryption, data retention, and how to revoke access or delete backups are documented in our PureFunction Backup Privacy Policy.
